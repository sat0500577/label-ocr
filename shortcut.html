아이폰 단축어로 만들기

아이폰에 들어 있는 문자 인식(Live Text)은 한국어를 이 웹앱보다 훨씬 정확하게 읽습니다. 설치할 것도, 인터넷도 필요 없습니다. 아래를 따라 5분이면 만듭니다.

만드는 순서

  1. 단축어 앱을 열고 오른쪽 위 +를 누릅니다.
  2. 동작 추가에서 사진 찍기를 검색해 추가합니다.
  3. 이미지에서 텍스트 추출을 검색해 추가합니다.
    이 동작이 아이폰 내장 문자 인식입니다.
  4. 텍스트 일치를 검색해 추가합니다. 입력이 앞 단계의 텍스트인지 확인하세요.
  5. 일치 항목에 아래 식을 붙여 넣습니다.

    [A-Za-z]*[가-힣]{2,}

    한글이 두 자 이상 이어지는 덩어리만 골라냅니다. 앞에 붙은 영문(HP, R)은 같이 가져오고 숫자·기호는 버립니다.
  6. 목록에서 항목 가져오기를 추가하고, 항목 가져오기를 첫 번째 항목으로 둡니다. 이것이 제품명입니다.
  7. 변수 설정을 추가해 이름을 제품명으로 합니다.
  8. 목록에서 항목 가져오기를 하나 더 추가합니다. 입력을 일치 항목으로 바꾸고, 인덱스의 항목 · 2로 설정합니다. 이것이 색상입니다.
  9. 변수 설정을 추가해 이름을 색상으로 합니다.
  10. 텍스트 동작을 추가하고 제품명 변수, /, 색상 변수를 차례로 넣습니다.
  11. 클립보드에 복사와 결과 보기를 추가합니다.
  12. 위쪽 이름을 라벨 읽기로 바꾸고 저장합니다.

홈 화면에 두기

단축어 목록에서 라벨 읽기를 길게 눌러 공유 → 홈 화면에 추가를 고릅니다. 아이콘을 누르면 바로 카메라가 열립니다.

결과가 이상할 때

  • 라벨을 화면에 크게, 정면으로 담아 찍으세요. 아이폰 문자 인식도 흐린 글자는 틀립니다.
  • 포장지의 작은 글씨가 먼저 잡히면 제품명 자리에 "모델명"이나 "제조사명" 같은 엉뚱한 말이 들어옵니다. 라벨만 화면에 들어오게 가까이서 찍으면 없어집니다. 자주 그러면 아래 고르는 방식으로 바꾸세요.
  • 제품명 뒤 숫자(HP딘버일자3의 3)는 위 식이 자동으로 버립니다.
  • 결과 창에서 글자를 직접 고칠 수 있습니다.

항상 맞게: 고르는 방식

자동으로 첫 두 개를 집는 대신, 인식된 낱말을 보여 주고 직접 두 번 누르는 방식입니다. 두 번 더 누르는 대신 틀릴 일이 없습니다.

위 순서에서 6번부터 9번까지를 지우고 아래로 바꿉니다.

  1. 목록에서 선택을 추가하고 입력을 일치 항목으로 둡니다. 프롬프트에 제품명 고르기라고 적습니다.
  2. 변수 설정으로 이름을 제품명으로 합니다.
  3. 목록에서 선택을 하나 더 추가하고 입력을 다시 일치 항목으로 둡니다. 프롬프트는 색상 고르기.
  4. 변수 설정으로 이름을 색상으로 합니다.

나머지(텍스트 합치기, 클립보드 복사, 결과 보기)는 그대로 둡니다.

이 웹앱은 언제 쓰나

단축어는 아이폰에서만 됩니다. 안드로이드나 PC에서, 또는 인터넷 없이 쓸 때는 이 웹앱을 그대로 쓰면 됩니다.
